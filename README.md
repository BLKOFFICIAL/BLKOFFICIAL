## `01 / THE ARCHITECT`

</div>

I'm **Adithyadev K** — a self-taught developer from **Kerala, India**, focused on building backend systems, developer platforms, SaaS products and full-stack applications.

I enjoy working where **software, infrastructure and product design** meet.

My work spans **Node.js APIs, system architecture, databases, cloud infrastructure, AI-assisted workflows, automation and game-server ecosystems**.

I prefer building systems with a **product-first mindset** — not just something that works once, but something that can be understood, maintained and improved over time.
